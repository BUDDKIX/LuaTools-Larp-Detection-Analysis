# Corrections and reproducibility

Evidence-based corrections are welcome, including from the software’s developers. Reference the report number/step, identify the tested build with a software hash, separate observation from inference, and explain whether your results concern the same build or a later release.

Do not post passwords, tokens, depot keys, personal IPs, account IDs, private paths, raw debugger listings, memory dumps or unsanitized logs. A failed negative test is not proof of safety; an injection import is not proof of maliciousness.

This repository does not provide a private vulnerability-reporting channel. Do not use public issues for sensitive exploit details or personal evidence. Public discussion should focus on the published statements and sanitized supporting information.
